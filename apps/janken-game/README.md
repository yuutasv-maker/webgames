# 脳バグ！後出しじゃんけん (Brain Janken Rush)

相手の手と指示（「勝て！」「負けろ！」「あいこ！」）を瞬時に判断してタップする、脳トレ×反射神経ゲーム！

## ゲーム仕様
- **目標クリア数**: 3回正解クリア（3ミスでゲームオーバー）
- **1問あたりの時間制限**: 5.0秒（時間経過でプログレスバーが減少）
- **クーポン獲得条件**: 3回クリア達成で限定クーポンGET！
- **誤タップ防止機能**: ゲーム終了時の即時ボタン無効化、800ms全画面演出、リザルト出現後500msのボタンガードを標準装備

## ファイル構成
- `index.html`: ゲーム画面HTML（ソロモード、対戦モード導線あり）
- `style.css`: 画面デザイン・アニメーション定義
- `script.js`: ゲームロジック（`GameLogic`）および演出制御
- `script.test.js`: 純粋関数の単体テスト
- `versus.html`: 1台おすそ分け2人対戦モード画面HTML
- `versus.css`: 対面対戦専用スタイル（P1: 180度反転、マルチタッチ対応）
- `versus.js`: 対戦ロジック（`JankenVersusLogic`）および演出制御
- `versus.test.js`: 対戦ロジックの単体テスト

## 👥 2人対戦モード（Versus Mode: versus.html）

1台のスマートフォンまたはPCを机に置き、対面でリアルタイムに後出し判断勝負ができるモードです。

* **画面構成**: 画面上下2分割（中央共通ステージに相手の手と指令、上側P1は奥の相手向けに180度反転、下側P2は手前向け）
* **操作**:
  * スマホ/タブレット: P1/P2それぞれのじゃんけんボタン（グー・チョキ・パー）をタップ（マルチタッチ対応）
  * PC:
    * P1: `A` (グー) / `S` (チョキ) / `D` (パー)
    * P2: `J` (グー) / `K` (チョキ) / `L` (パー)
* **ルール**: **3問先取（First to 3）**
* **判定・テンポ**:
  * 早く正しい手を出したプレイヤーに **+1pt**
  * 誤答時は **仕切り直しなしで即座に相手に +1pt**（スピーディーな決着）
  * 次の問題へは自動的にテンポよく移行（800ms）

## 🧪 テスト実行

node webgames/apps/janken-game/versus.test.js
