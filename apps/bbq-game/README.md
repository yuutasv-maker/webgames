# 爆速BBQ串メーカー (BBQ Skewer Rush!)

## 概要
制限時間（20秒）以内に、上部に表示されるオーダー通りの順番で具材（肉、玉ねぎ、ピーマン）をタップし、どれだけ多くの串を完成させられるかを競うアクションゲームです。

## 主な機能と仕様
- **ゲームフロー**:
  - `READY`: スタート前のモーダル表示。
  - `PLAYING`: 20秒間のカウントダウンタイマーが作動し、具材をタップして串を作るフェーズ。
  - `RESULT`: 制限時間終了後の結果表示（作成した串の本数と履歴、およびクーポン獲得判定）。
  - **クーポン獲得条件**: 制限時間内に **10本以上** の串を完成させると、1日1回限定の海の家特別クーポンが獲得できます。

- **ゲームルール**:
  - 毎回ランダムな長さ（例：3〜5個）のオーダーが生成される。
  - プレイヤーは下にある具材ボタン（🍖、🧅、🫑）をタップして串に刺していく。
  - 串は「下から上へ」と積み上がっていく視覚表現。
  - オーダー通りの順番で具材を揃えると串が完成し、「NICE!✨」という成功エフェクトが表示され、次のオーダーへ進む。
  
- **UI / UX**:
  - グラスモーフィズムを活用したモダンなパネルデザイン。
  - **レスポンシブ・スマホ対応**: `viewport`のズーム無効化等により、スマホでの高速タップにも対応。
  - **履歴機能**: タイムアップ後の結果画面では、何本完成させたかのスコアだけでなく、実際に完成させた串の具材履歴がリスト表示されます。
  - **アイコン（ファビコン）**: 🍖（骨付き肉）の絵文字SVGファビコンを採用。

## ディレクトリ構成
- `index.html`: ゲーム画面のDOM定義。
- `style.css`: UIのスタイル、アニメーション（成功時のポップアップ等）。
- `script.js`: ゲームループ（タイマー）、オーダー生成アルゴリズム、具材の判定ロジック。
