Studio OWL Event System

全ファイル網羅・完全マニュアル

このシステムは、スタジオOWLのウェブサイトにおけるイベント管理を自動化・効率化するために構築されました。
CSVによる一括更新ツールと、各種機能を一本化したWeb管理アプリ（単発登録、チケット予約作成、参加型イベント出力）で構成されています。

クイックスタート

Web管理アプリ（統合版）

スマホやPCのブラウザから、イベントの単発登録・チケット選択肢の作成・参加型イベントの出力が行えます。

起動.command (Mac) / 起動.bat (Win) を実行

スケジュール一括更新 (CSV)

複数のイベントをExcelで編集し、一括でWordPressに流し込みます。

services/schedule-batch/run_update.sh (.bat) を実行

自動起動・常時稼働について

Macの起動と同時に裏側でWebアプリを動かし続け、スマホからいつでもアクセスできるようにする方法です。

手動での起動・停止 (start / stop)

ターミナルから以下のコマンドを実行することで、バックグラウンドでの動作をコントロールできます。

# 裏側でWebアプリを起動する
./services/schedule-batch/run_form.sh start

# 起動中のWebアプリを停止する
./services/schedule-batch/run_form.sh stop

Mac起動時の自動起動 (plistの調整)

Macの自動起動プログラム（plist）で run_form.sh を登録している場合、正しいパスに設定してください。
~/Library/LaunchAgents/com.studio-owl.form-app.plist のファイル内の <string>run_form.sh</string> の箇所を、<string>services/schedule-batch/run_form.sh</string> に書き換えてください。

※自動起動機能を完全に無効化したい場合は、ターミナルで以下のコマンドを実行します。 

launchctl unload ~/Library/LaunchAgents/com.studio-owl.form-app.plist
