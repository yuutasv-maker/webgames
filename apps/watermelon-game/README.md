# Watermelon Smash! 🍉 (スイカ割りゲーム)

## 概要
左右に高速で動くカーソルをタイミングよくタップして、ゲージのど真ん中（PERFECTゾーン）で止めるタイミングゲームです。

## 主な機能と仕様
- **ゲームフロー**:
  - `IDLE`: カーソルが左右に動き続けている待機状態。
  - `PLAYING`: `HIT!!` ボタンを押した瞬間の判定処理。
  - `RESULT`: 結果（CRITICAL, PERFECT, GREAT, GOOD, MISS）に応じた演出とスコア表示。
  - **クーポン獲得条件**: 最上位判定 `CRITICAL`（芯の直撃）達成時のみクーポンが進呈されます。

- **UI / UX**:
  - 夏の海辺をイメージした鮮やかなグラデーション背景とグラスモーフィズムデザイン。
  - **画面固定（スマホ特化）**: `position: fixed;` と `overflow: hidden;`、および `touch-action: none;` により、連打や誤タップによるバウンススクロール・ズームインを完全に防止しています。
  - **ターゲットゲージ (`.target-zone`)**:
    - ゲージ全体の40%が判定エリア。
    - **グラデーション**: 端（GOOD）の濃い緑から、中間（GREAT）の黄緑まではシームレスなグラデーションで色が変化します。
    - **PERFECT / CRITICALゾーン**: 中央エリアは端の「薄い赤」から中心（CRITICAL）の「濃い赤」へとシームレスなグラデーションで変化し、狙うべき芯が自然にわかるようになっています。
  - **カーソル (`.cursor`)**:
    - 赤色系の背景でも見失わないよう、黒色（ダークグレー）の縦棒に黒のシャドウをつけて視認性を高めています。
  - **SVGアニメーション**: 
    - 中央のスイカはSVGで描画されており、HIT（GOOD以上）で綺麗に左右に割れるアニメーション、MISSでブルブルと震える（shake）アニメーションがCSSで実装されています。
  - **アイコン（ファビコン）**: 🍉（スイカ）の絵文字SVGファビコンを採用。

## ディレクトリ構成
- `index.html`: ゲーム画面のDOM定義、SVGアセット（スイカ）の埋め込み。
- `style.css`: ゲームのスタイル、ゲージのグラデーション定義、アニメーション処理、画面スクロール固定。
- `script.js`: カーソルの移動ロジック（`requestAnimationFrame`）、判定ロジック。
