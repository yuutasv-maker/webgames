# 最後の一本フランクフルト 🌭 (Frankfurt Grab)

8bitレトロファミコン風の瞬間反射神経計測ミニゲームです。鉄板の上で香ばしく焼かれる最後の一本のフランクフルトを巡り、3人のライバル客と早取り勝負を繰り広げます。

## 🎮 ゲーム仕様

* **コンセプト**: 星のカービィ「刹那の見斬り」風の瞬間タップ対戦
* **制限時間 / 試行**: 全3ラウンド（3回挑戦）
* **対戦相手**:
  * ROUND 1: 観光客 👒 (反応目安: 420ms)
  * ROUND 2: 海の男 🏄‍♂️ (反応目安: 330ms)
  * ROUND 3: 腹ペコ店長 👨‍🍳 (反応目安: 280ms)
* **合格基準**: ベストタイム **300ms以内**（1回でも達成でクーポン獲得）
* **ペナルティ**: 合図が出る前のフライングタップはお手つき（火傷アニメーション＋9999ms扱い）

## 🛠 技術スタック

* **描画**: 低解像度 HTML5 Canvas 2D (240×360px) + CSS等倍拡大 (`image-rendering: pixelated;`)
* **サウンド**: Web Audio API（外部ファイル不使用の完全プログラム生成：ノイズ鉄板音、矩形波合図SE、アルペジオ奪取音）
* **連携**: `CouponManager`（共通クーポン基盤）による日次獲得判定とクーポン画面連携

## 👥 2人対戦モード（Versus Mode: versus.html）

1台のスマートフォンまたはPCを机に置き、対面でリアルタイムに早取り勝負ができるモードです。

* **画面構成**: 画面上下2分割（上側P1は奥の相手向けに180度反転表示、下側P2は手前向け）
* **操作**: 
  * スマホ/タブレット: 画面上半分タップ（P1）/ 画面下半分タップ（P2）※マルチタッチ対応
  * PC: `A` / `W` キー（P1）、`L` / `Enter` / `↓` キー（P2）
* **ルール**: **3本先取（First to 3）**
* **お手つき**: 合図前のタップは火傷。**1回目は警告⚠️（点数変動なし・仕切り直し）**、**2回目で相手に1本献上**
* **鍔迫り合い（DRAW）**: 5ms未満の同時タップは引き分けで再勝負
