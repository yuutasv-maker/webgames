Studio OWL Event System

全ファイル網羅・完全マニュアル

このシステムは、スタジオOWLのウェブサイトにおけるイベント管理を自動化・効率化するために構築されました。 CSVによる一括更新と、ブラウザからの単発登録の両方に対応しています。

クイックスタート

一括更新 (CSV)

複数のイベントをExcel感覚で一気に更新します。

run_update.bat を実行

単発登録 (GUI)

ブラウザから画像付きで1件ずつ登録します。

run_form.bat を実行

自動起動・常時稼働について

Macの起動と同時に裏側でシステムを動かし続け、スマホからいつでもアクセスできる運用方法です。

手動でのコントロール (start / stop)

ターミナルから以下のコマンドを実行することで、バックグラウンドでの動作を自由に管理できます。

# 裏側（バックグラウンド）でフォームを起動する
./run_form.sh start

# 起動中のフォームを強制停止する
./run_form.sh stop

Mac起動時の完全自動スタート (plist)

com.studio-owl.form-app.plist という仕組みを用いて、Mac起動時に自動で ./run_form.sh start が実行されるよう設定されています。
これにより、Macの電源を入れてログインするだけで、スマホから http://(MacのローカルIP):5001 にアクセスしてフォームを利用できます。

※この自動起動機能をシステムから完全に削除（無効化）したい場合は、ターミナルで以下のコマンドを実行してください。 

launchctl unload ~/Library/LaunchAgents/com.studio-owl.form-app.plist
