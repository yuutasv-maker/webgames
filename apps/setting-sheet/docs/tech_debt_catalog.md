# 技術的負債・暫定対処 カタログ

本ドキュメントは、MVP（Phase1）リリース時点において「あえて割り切った」実装や、将来的に改善すべき技術的負債をリスト化したものです。

| 該当箇所 | 暫定対処・車輪の再発明の内容 | 放置した場合のリスク | 本来あるべき姿・将来の改善案 |
| :--- | :--- | :--- | :--- |
| `logic.js` <br> `generateUUID()` | `Math.random` と `Date.now` を用いた疑似的なUUID生成（車輪の再発明）。 | 厳密な一意性は保証されない。数ミリ秒の間に超高頻度で同時生成されると重複するリスクがある。 | 標準の `crypto.randomUUID()` への置換、またはnpmの `uuid` パッケージの導入。現状はスタンドアロン要件のため許容。 |
| `main.js` <br> `FAT_FINGER_OFFSET` | スマホの指でアイコンが隠れないよう `40px` 上にずらす処理が固定値（Magic Number）になっている。 | 解像度の高い/低い端末間でズレが大きすぎる、あるいは小さすぎる問題が出る可能性がある。 | 画面サイズ（DPI）やアイコンサイズに対する相対値（%やrem）での計算への変更。 |
| `index.html` <br> `html2canvas` | `<script src=".../html2canvas.min.js">` によるCDNからの直接読み込み。 | オフライン環境で動作しない。CDN障害時にエクスポート機能が使えなくなる。 | npm経由でのインストールと、webpack/Vite等を用いたバンドルへの移行。 |
| `index.html` <br> アイコンの配置 | `<div data-type="...">` と `<img>` がハードコーディングされている。 | 機材の種類が増減するたびにHTMLを直接変更する必要がある。 | `logic.js` 側に機材のマスターデータ（設定オブジェクト）を持ち、JSでパレットのDOMを動的生成する形へ変更。 |
