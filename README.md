## クイックスタート

**Webフォーム起動（Mac）:**
```bash

```

**スケジュール一括更新（Mac / Linux）:**
```bash
./services/schedule-batch/run_update.sh
```

**スケジュール一括更新（Windows）:**
```cmd
services\schedule-batch\run_update.bat
```
