# 映えアサイー職人 (Acai Bowl Maker)

## 概要
お手本のフルーツ（トッピング）配置を数秒間記憶し、自身のボウルに同じ配置を再現する「記憶＆スピードゲーム」です。
素早く正確に配置できたかを競います。

## 主な機能と仕様
- **ゲームフロー（状態遷移）**: 
  - `START`: 初期状態。スタートボタン待ち。
  - `MEMORIZE`: お手本が表示される記憶フェーズ（3秒間）。
  - `PLAY`: プレイヤーがトッピングを選択し、自身のボウルに配置するフェーズ。
  - `RESULT`: 判定フェーズ。成功/失敗とクリアタイムが表示される。

- **UI / UX**:
  - アサイーをイメージした紫とピンクのグラデーション背景。グラスモーフィズムデザイン。
  - **レスポンシブ・スマホ対応**: `viewport`の固定設定およびCSS（`touch-action: manipulation`, `overflow: hidden`）により、誤タップによるズームや画面のスクロールを防止。
  - **トッピングパレット**:
    - 6種類のフルーツボタンが Grid レイアウトによって、常に「3個×2段」でバランス良く配置されます。
    - ゲーム開始前（START）およびお手本記憶中（MEMORIZE）は、プレイヤーの視界や記憶の邪魔にならないようパレット全体が非表示（`display: none`）になります。
  - **カウントダウン演出**:
    - 記憶フェーズ中、お手本ボウルの上部に大きなポップアップアニメーション付きのカウントダウン（3, 2, 1, START!）が表示されます。
    - カウントダウン文字は背景に埋もれないよう「鮮やかな黄色」＋「太い濃紫の縁取り」になっており、お手本のフルーツや「お手本」のテキストラベルと重ならないように位置調整されています。
  - **結果表示**:
    - 正解時はクリアタイムが表示されます。
    - 不正解時および正解時ともに、本来の「正解のお手本」が2x2のアイコン（絵文字）グリッドとして分かりやすく表示されます。
  - **アイコン（ファビコン）**: 🫐（ブルーベリー）の絵文字SVGファビコンを採用。

## ディレクトリ構成
- `index.html`: ゲーム画面のDOM定義およびUI配置。
- `style.css`: ゲーム全体のスタイル、アニメーション（CSS Keyframes）、UIの非表示制御など。
- `script.js`: ゲームロジック、状態管理（FSM）、イベントハンドリング。
